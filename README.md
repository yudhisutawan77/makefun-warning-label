## The entry

> WARNING: This human ships with no manual, no warranty, and one (1) unresolved childhood. Handle with sarcasm.

## How it works

`main.py` writes a single-line safety warning label for human beings (109 characters, inside the 160-character gate) to `/output/entry.txt`.

Run it:

```sh
python3 main.py
```
